# Осколки Эфира (v0.3) — Godot 4

Офлайн-RPG для Android в духе MMORPG: прокачка как в Enshrouded и Path of Exile.
Движок **Godot 4.7.2**, язык GDScript, рендерер Mobile. Персонажи и монстры — анимированные glTF-модели (CC0, см. «Ассеты и лицензии»); окружение пока собирается из примитивов в коде.
Предыдущая версия на Unity лежит в ветке [`unity`](../../tree/unity).

## Что нового в v0.3.2
- Хват оружия переделан по костям кисти: оружие крепится к кости `hand_r`/`hand_l` (BoneAttachment3D), ось модели идёт
  по оси кулака (от мизинца к большому пальцу), кулак смыкается в точке хвата (посох — на 1/3 высоты, меч — по рукояти, лук — по центру).
- `GripAlign` (SkeletonModifier3D) доворачивает кисть после анимации: посох и лук в стойке, на бегу и при касте стоят вертикально
  навершием вверх, меч в стойке поднят; во время взмахов работает исходная анимация.
- Проверено крупными планами (спереди/сбоку/кисть) для мага, некроманта, стихийника, воина, паладина, лучника и гоблина.

## Что нового в v0.3.1
- **Версия для ПК (Windows x86_64)**: управление клавиатурой и мышью, сенсорные кнопки скрыты.
  - WASD/стрелки — движение, ЛКМ — атака (удержание — серия), ПКМ + мышь — камера, колесо — зум
  - 1/2/3 — умения, Пробел — прыжок, Shift — кувырок, H — зелье, E — торговец
  - I/C — герой, T/N — таланты, M — большая карта, Esc — меню/закрыть окно
  - Меню → настройки: графика (низкое/среднее/высокое), полный экран/окно, разрешение окна, масштаб интерфейса
- Исправления по отзывам: посох мага в руке (атаки посохом, а не рукой), щит паладина лицевой стороной,
  прокрутка списков пальцем (лавка, инвентарь, таланты), не обрезается описание талантов,
  описание класса не перекрывает модель, HP не превышает максимум, надпись торговца над навесом,
  в лавке нет повторов, добыча притягивается к герою, читаемые подписи умений.
- Эффекты: светящийся кристалл на посохе, ореол и вспышка снарядов, искры попаданий, дымка при гибели врага, столб света при новом уровне.

- Мини-карта-компас с метками (босс, торговец, портал, враги) и строкой цели.
- Подсказки при первом запуске (движение, атака, прыжок/кувырок, таланты, лавка, босс).

## Что нового в v0.2
- **Реалистичные персонажи** вместо примитивов: модели мужчины и женщины на общем скелете (65 костей) с PBR-материалами (albedo + normal + ORM).
  - 40 анимаций: покой, ходьба, бег, спринт, прыжок, атаки мечом, заклинания, выстрел, удар, получение урона, смерть и другие.
  - AnimationTree: локомоция по скорости, прыжок, разовые действия (на бегу — только верх тела), смерть.
  - Снаряжение по классу: Воин — красная броня с наплечником, меч и щит; Лучник — зелёная куртка, лук и колчан; Маг — синяя одежда и посох.
  - Превращения меняют облик: Берсерк (тёмно-красный, крупнее, искры), Паладин (золото, нимб, свет), Стихийник (синее свечение, сферы-стихии), Некромант (капюшон, бледная кожа, зелёный дым), Тень (чёрный капюшон, фиолетовые глаза), Друид (облик волка).
- **Монстры с анимациями**: слизень, волк, скелет-воин (меч и щит), скелет-лучник (лук), гоблин-громила (топор), босс «Древний тролль» (2,3 м, удар по площади с анимацией). После смерти тело остаётся на земле, затем исчезает.
- **Редактор внешности** с вкладками «Основа / Тело / Лицо / Волосы»:
  - 18 ползунков лица (blendshapes): ширина и длина лица, челюсть, подбородок, скулы, щёки, размер, расстояние и высота глаз, длина, ширина носа и переносица, губы, ширина рта, высота бровей, надбровные дуги, размер и заострённость ушей;
  - 6 причёсок, 14 цветов волос, 2 вида бровей, борода (длина, густота), объём причёски, 8 цветов глаз, 10 тонов кожи, рост, телосложение, размер головы;
  - 7 пресетов лица, кнопки «Случайно» и «Сброс лица»;
  - крупный план лица на вкладках «Лицо» и «Волосы», вращение превью пальцем;
  - всё сохраняется в слот персонажа (старые сохранения v0.1 конвертируются автоматически).
- **Прыжок**: кнопка «Прыжок» на HUD (на ПК — J), гравитация, «время койота» (0,14 с) и буфер нажатия (0,15 с), высота около 1,5 м.
- **Арена босса доступна**: платформа 0,8 м с пологим пандусом от тропы (юг) и уступом-ступенькой с востока, на которые можно запрыгнуть.
- **Свет**: процедурное небо, освещение от неба, ACES-тонмаппинг, мягкое свечение, туман с рассеянием солнца, мягкие тени до 45 м. Мобы скрываются дальше 70 м (visibility range).

## Структура
```
scenes/            main_menu.tscn, zone.tscn
scripts/autoload/  db.gd (данные, формулы), game.gd (сохранения, сцены, уведомления)
scripts/game/      игрок, враги, камера, спавнеры, лут, снаряды, построение зоны;
                   char_visual.gd (персонаж: модель, морфы, анимации, оружие, облики превращений),
                   char_assets.gd (палитры, пресеты, материалы), mob_model.gd (монстры)
assets/characters/ human_{m,f}.gltf (модели + морфы лица), anims_{m,f}.gltf (анимации), tex/ (текстуры)
assets/mobs/       slime, wolf, skeleton (.glb);  assets/props/ — оружие и щиты (.glb)
assets/shaders/    skin, hair, eyes, outfit (перекраска одежды без лишних текстур)
tools/assets/      пайплайн сборки моделей на Python (без Blender)
scripts/ui/        HUD, создание персонажа, дерево талантов, инвентарь, пауза
data/              talent_tree.json
tests/             smoke_test (headless), screens (снимки экрана)
```
Новая карта добавляется так: запись в `DB.ZONES`, свой builder по образцу `zone_builder.gd` и `target_zone` у портала.

## Сборка
- Windows: `godot --headless --path . --export-release "Windows Desktop" build/windows/OskolkiEfira.exe` (exe + pck рядом)
```bash
godot --headless --path . --import
godot --headless --path . res://tests/smoke_test.tscn      # смоук-тест, код выхода 0 = PASS
godot --headless --path . --export-debug "Android" build/oskolki-efira.apk
```
Для экспорта в настройках редактора Godot нужно указать путь к JDK 17, Android SDK и debug keystore.
Снимки экрана: `xvfb-run godot --path . --rendering-driver opengl3 --resolution 1920x1080 res://tests/screens.tscn` (сохраняет в `/workspace/rpg-shots/`).
Сборка идёт без Gradle, только arm64-v8a.

## Пайплайн ассетов
Готовые модели уже лежат в `assets/` — пересобирать их не нужно. Исходники (паки Quaternius) скачиваются в `~/assets_dl`, затем:
```bash
python3 tools/assets/build_chars.py   # человек м/ж: склейка частей, атлас головы, 18+3 морфа лица (процедурно)
python3 tools/assets/build_anims.py   # ретаргет 40 клипов Universal Animation Library на скелет персонажа
```
Скрипты работают на чистом Python + numpy (`tools/assets/gltfio.py`), без Blender.
