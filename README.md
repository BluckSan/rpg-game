# Осколки Эфира (рабочее название) — v0.1

Офлайн мобильная action-RPG в стиле MMORPG на Unity (Android). Вдохновение: Enshrouded, Path of Exile.

## Что есть в v0.1
- **Создание персонажа как в MMORPG**: до 6 слотов, пол, рост, телосложение, цвет кожи, лицо (борода/шрам), 6 причёсок, цвет волос и глаз, имя, класс (Воин / Лучник / Маг), 3D-превью с вращением пальцем.
- **Стартовая зона «Пепельная долина»** (одиночная): лагерь с костром (точка возрождения), луг слизней, лес волков, кладбище скелетов, лагерь гоблинов, руины с боссом «Древний тролль», портал на глобальную карту (закрыт до следующих версий).
- **Управление для телефона**: плавающий джойстик слева, свайп справа — поворот камеры, два пальца — зум; кнопки атаки, двух умений класса, умения пути и зелья. Автонаведение на ближайшего врага.
- **Прокачка**: уровни персонажа (очки талантов), отдельное **мастерство класса** (открывает умения, +3% урона за уровень).
- **Большое пассивное дерево талантов** (147 узлов, PoE-стиль): 6 регионов — Ярость, Вера, Стихии, Тлен, Тени, Дикость. Перемещение и зум, малые/особые/ключевые таланты, сброс.
- **Пути превращения** (ascendancy): Берсерк, Паладин, Стихийник, Некромант, Тень, Друид-зверь (облик медведя). Открываются через ключевой талант региона + 6 очков в нём + 8 уровень. Меняют внешность, дают бонусы и новое умение.
- **Добыча**: золото, зелья, предметы 4 редкостей (оружие, броня, шлем, кольцо) со случайными свойствами; инвентарь на 30 ячеек, экипировка, продажа.
- **Сохранение** на устройство (JSON в `Application.persistentDataPath/saves`), автосохранение каждые 30 сек и при сворачивании.

## Структура
```
Assets/Scripts/Core      — данные персонажа, сохранения, сессия, реестр зон, точки входа сцен
Assets/Scripts/Data      — классы, характеристики, генератор добычи
Assets/Scripts/Talents   — дерево талантов (загрузка JSON), пути превращения
Assets/Scripts/Gameplay  — игрок, камера, бой, враги, спавнеры, добыча, построение зоны
Assets/Scripts/UI        — интерфейс кодом (uGUI): меню, создание героя, HUD, дерево, инвентарь
Assets/Scripts/Visual    — модели из примитивов, процедурная анимация, эффекты
Assets/Resources/Talents/talent_tree.json — данные дерева (генерирует tools/gen_talent_tree.py)
Assets/Editor            — генерация сцен/настроек (меню RPG → Настроить проект) и сборка APK
```
Сцены (`MainMenu`, `StarterZone`) создаются автоматически скриптом `ProjectSetup` — в них только точка входа, всё остальное строится кодом.

## Как добавить глобальную карту
1. Написать `GlobalMapBuilder` по образцу `StarterZoneBuilder`.
2. В `ZoneBootstrap` добавить ветку для `zoneId == "global"`.
3. Добавить `Assets/Scenes/GlobalMap.unity` в `ProjectSetup.Scenes` и поставить `available = true` в `ZoneRegistry`.
Портал в стартовой зоне уже ведёт в зону `global`; состояние зон хранится в `CharacterData.zones`.

## Сборка
Unity 6000.3 LTS (6.3) + Android Build Support (IL2CPP, arm64).
```
tools/build_apk.sh            # -> Builds/rpg-game.apk
```
или в редакторе: меню **RPG → Собрать APK**.

Графика — только примитивы Unity (без сторонних ассетов), шрифт — встроенный.
