# Осколки Эфира (v0.1) — Godot 4

Офлайн-RPG для Android в духе MMORPG: прокачка как в Enshrouded и Path of Exile.
Движок **Godot 4.7.2**, язык GDScript, рендерер Mobile. Вся графика собирается из примитивов в коде, внешних ассетов нет.
Предыдущая версия на Unity лежит в ветке [`unity`](../../tree/unity).

## Что есть в v0.1
- **Создание персонажа как в MMORPG**: 6 слотов, имя, 3 класса (Воин, Лучник, Маг), пол, рост, телосложение, цвет кожи, лицо, причёска, цвет волос и глаз. Есть 3D-превью: его можно вращать пальцем.
- **Стартовая зона «Пепельная долина»** (одиночная), состоит из областей:
  - лагерь (точка возрождения);
  - луг со слизнями;
  - лес с волками;
  - кладбище со скелетами;
  - лагерь гоблинов;
  - руины с боссом «Древний тролль»;
  - портал на глобальную карту (откроется в следующих версиях, требуется 10 уровень).
- **Мобильное управление**:
  - виртуальный джойстик;
  - свайп для поворота камеры;
  - щипок для зума;
  - кнопки атаки, 3 умений и зелья.
  Поддерживается мультитач.
- **Опыт и уровни.** Отдельно идёт мастерство класса: на 3-м мастерстве открывается третье умение.
- **Дерево талантов** в стиле PoE: 147 узлов, 6 регионов. Дерево хранится в `data/talent_tree.json`, генератор лежит в `tools/gen_talent_tree.py`.
- **6 превращений** (открываются регионами дерева с 8 уровня), у каждого своё умение и бонусы:
  - Берсерк;
  - Паладин;
  - Стихийник;
  - Некромант;
  - Тень;
  - Друид-зверь.
- **Добыча, инвентарь (30 ячеек), снаряжение (4 слота), характеристики, продажа предметов.**
- **Сохранения в JSON** (`user://saves/char_<id>.json`): автосохранение каждые 30 с и при сворачивании приложения.
- **Русский интерфейс**, шрифт Rubik (SIL OFL, `fonts/OFL.txt`).

## Структура
```
scenes/            main_menu.tscn, zone.tscn
scripts/autoload/  db.gd (данные, формулы), game.gd (сохранения, сцены, уведомления)
scripts/game/      игрок, враги, камера, спавнеры, лут, снаряды, построение зоны
scripts/ui/        HUD, создание персонажа, дерево талантов, инвентарь, пауза
data/              talent_tree.json
tests/             smoke_test (headless), screens (снимки экрана)
```
Новая карта добавляется так: запись в `DB.ZONES`, свой builder по образцу `zone_builder.gd` и `target_zone` у портала.

## Сборка
```bash
godot --headless --path . --import
godot --headless --path . res://tests/smoke_test.tscn      # смоук-тест, код выхода 0 = PASS
godot --headless --path . --export-debug "Android" build/oskolki-efira.apk
```
Для экспорта в настройках редактора Godot нужно указать путь к JDK 17, Android SDK и debug keystore.
Сборка идёт без Gradle, только arm64-v8a.
